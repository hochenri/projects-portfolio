## 📊 Data & Machine Learning

### Image Generation (Deep Learning)

- **[Denoising Autoencoder for Image Generation](https://github.com/hochenri/projects-portfolio/blob/1b04a13a6c40b25cead813aa3f239cd944f525f1/Denoising_Generator_Artist.ipynb)** — Trains a denoising autoencoder to reconstruct and generate images. Demonstrates **neural network architecture design, training loops, and latent-space sampling**.
- **[Simplified GAN-Inspired Image Generator](https://github.com/hochenri/projects-portfolio/blob/main/Simplified%20Image%20Generator.ipynb)** — A lightweight, GAN-inspired generator built from scratch to illustrate **adversarial training concepts** without the overhead of a full GAN.

**Skills demonstrated:** deep learning, autoencoders, generative models, TensorFlow, model evaluation.

### Data Engineering (ETL)

- **[Healthcare ETL Job](https://github.com/hochenri/projects-portfolio/blob/main/Healthcare%20ETL.ipynb)** — End-to-end **ETL pipeline** that extracts and aggregates patient data from proprietary databases (sanitized, no confidential data). Demonstrates **schema design, transformation logic, and aggregation**.
- **[Weather Anomalies ETL Job](https://github.com/hochenri/projects-portfolio/blob/main/Weather%20ETL.ipynb)** — **ETL pipeline** pulling weather data from a mock API and producing a dataset of **weather anomalies**. Demonstrates **API ingestion, validation, and derived-feature generation**.

**Skills demonstrated:** ETL design, API ingestion, data cleaning, aggregation, reproducibility.

### Data Analysis & Dashboards

- **[Flight Incidents Dashboard](https://lookerstudio.google.com/reporting/03e20fe5-95be-42b7-af53-85585c5510e0)** — Public **Looker Studio dashboard** visualizing flight incidents gathered from news reports. Demonstrates **data collection, cleaning, and interactive visualization**.
- **[Speed Dating Experiment Analysis](https://github.com/hochenri/projects-portfolio/blob/main/Speed%20Dating%20Experiment.ipynb)** — **Exploratory data analysis** of survey results from speed-dating events, driving actionable insights. Demonstrates **statistical analysis, hypothesis testing, and storytelling with data**.

**Skills demonstrated:** exploratory data analysis, visualization, statistical reasoning, business insight generation.
